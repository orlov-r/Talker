# Question definitions (reserved)

This directory prepares for the next content migration: separate private
question definitions that lessons can reference and reuse.

No question JSON has been extracted yet. Current lesson files in `lessons/`
still embed their sources, and the loader does not read this directory.
The reference format and validation will be defined during that migration.
Keep questions and answer keys server-side.

See [the current lesson schema](../README.md#implemented-schema) and
[future enhancements](../../docs/todo.md).
